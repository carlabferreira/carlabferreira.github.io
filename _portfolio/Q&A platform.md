A Q&A forum for the UFMG community, developed as a course project for Software Engineering in the first semester of 2025. The main objective of this project is to develop a portal covering questions related to university life, as well as enrollment inquiries and coursework exercises. 

<img src='/images/forum.jpeg' alt='forum' width='600'>

Code available at [https://github.com/carlabferreira/ForumUFMG](https://github.com/carlabferreira/ForumUFMG)

### Objectives and Key Features:
The main objective of this project is to develop a Q&A forum for the UFMG community, covering questions related to university life as well as enrollment inquiries and coursework exercises. Key features to be implemented include:

- User registration and login (Authentication)
- Creation of new discussion topics/questions
- Replying to an existing topic/question
- Home page for registered and unregistered users (topic viewing)
- Option to delete a topic/question
- Creation of tags to categorize topics
- Question search functionality

### Technology Stack:
- Version Control: Git and GitHub
- Languages & Tools: JavaScript (including Node.js, React, jQuery), HTML, CSS, and MySQL
