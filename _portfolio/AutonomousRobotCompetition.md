A project featuring an autonomous robot built using an Arduino, an acrylic chassis, DC motors, and various sensors. It is designed to search for and retrieve blocks, simulating disaster scenarios. Developed during the "Introduction to Robotics" course in 2026.

Code available and specifications at [https://github.com/carlabferreira/Robotics](https://github.com/carlabferreira/Robotics)

### Objectives and Key Features:

- Localization on the base using polarized lights.
- Mapping and navigation via line following and/or odometry.
- Color identification for block-handling logic.
- Block capture using servomotors and 3D-printed grippers.
